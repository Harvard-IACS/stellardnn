01 / NeuroDiffEq

Physics-informed neural networks

We study neural approaches to differential equations, including transfer learning, uncertainty quantification and learned representations of solution families. NeuroDiffEq provides an open-source Python foundation for this work.

NeuroDiffEq software ↗
02 / NeuroDiffHUB

Sharing neural solutions

NeuroDiffHub was developed as a platform for storing and sharing neural solutions of differential equations. The original project description is retained in the research archive.

NeuroDiffEq research ↗
03 / Astromer

Representations for astronomical time series

ASTROMER learns embeddings of astronomical light curves using transformer models. Subsequent work explores adaptation across surveys, few-shot classification and multivariate light curves.

ASTROMER resources ↗
04 / NNEHT

Neural methods for black-hole observations

Research explores computer vision and deep learning for characterizing black-hole images and estimating physical parameters from Event Horizon Telescope observations.

Project archive ↗
05 / RCTorch

Reservoir computing

RcTorch is a PyTorch reservoir-computing package with automated hyperparameter optimization. Related work explores unsupervised reservoir methods for ordinary differential equations.

RcTorch software ↗
06 / Cosmology

Learning cosmological dynamics

Neural solutions of the equations governing cosmological models support parameter inference. Related research investigates gravitational duals and physically informed representations.

Related publications ↗
07 / Cybersecurity

Machine learning for cybersecurity

Collaborative work with John Carter, Spiros Mancoridis and colleagues investigates behavioral malware detection using system-call representations, BERT-based models and contrastive learning. Studies examine security in routers and IoT networks, including sysBERT, contrastBERT and calBERT.

Selected research

  • calBERT: Securing Routers Serving IoT Networks using Contrastive Augmented Learning (2026)
  • contrastBERT: Behavioral Anomaly Detection for Malware Using Contrastive Learning (2025)
  • sysBERT: Improved Behavioral Malware Detection using BERT Trained on sys2vec Embeddings (2025)

08 / ADSML

Machine learning for scientific literature

Work with the SAO/NASA Astrophysics Data System applies language models and retrieval methods to scientific text, including named entities, concept discovery and local citation recommendation.
