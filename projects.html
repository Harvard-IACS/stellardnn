Research

Machine learning research in astronomy, physics, and cybersecurity.

Explore active projects

NeuroDiffHub

NeuroDiffHub was designed as a central repository for neural network solutions to differential equations. Its web application let researchers search for equations, and its API provided tools to save and load solutions.

NeuroDiffEq

Physics-informed neural networks offer a way to solve differential equations that are difficult to solve analytically. Our research uses neural networks to preserve physical symmetries, solve Hamiltonian systems, and improve performance with generative adversarial networks. The open-source NeuroDiffEq library makes these methods available to researchers.

ASTROMER model

ASTROMER learns representations of astronomical light curves from unlabeled data. The pretrained transformer can adapt to new surveys. Its light-curve embeddings reduce the computation needed to train classifiers and regressors and have achieved state-of-the-art results in light-curve classification. The project provides a Python library, data, and tutorials.

Event Horizon Telescope imaging

In 2019, the Event Horizon Telescope Collaboration released the first image of the supermassive black hole M87*. We use deep learning to estimate physical parameters from these observations and simulations. These estimates help test theories of gravity and study matter and magnetized jets near black holes.

Reservoir computing

Reservoir computers train quickly and handle sequential data well, but their performance depends strongly on hyperparameters. RcTorch is a PyTorch package that automates hyperparameter tuning. We also use unsupervised reservoir computing to find approximate solutions to ordinary differential equations.

Cosmology-informed neural networks

We use neural networks to solve the equations governing the background dynamics of the universe. We studied four models, including ΛCDM, a quintessence model with exponential potential, and the Hu-Sawicki f(R) model. We use the solutions and observational data to estimate model parameters. Related work uses holographic methods to calculate bubble wall velocity during a cosmological phase transition, which helps determine the resulting gravitational-wave spectrum.

Astrophysics Data System machine learning

The SAO/NASA Astrophysics Data System (ADS) is a digital library operated by the Smithsonian Astrophysical Observatory under a NASA grant. Its three collections contain more than 15 million records across astronomy, astrophysics, physics, and general science, including arXiv e-prints. The ADSML project uses this literature to train astroBERT and develop tools for named entity recognition and concept discovery.

Machine learning for cybersecurity

Collaborative work with John Carter, Spiros Mancoridis, and colleagues investigates behavioral malware detection using system-call representations, BERT-based models, and contrastive learning. Studies examine security in routers and Internet of Things networks.

  • calBERT: Securing Routers Serving IoT Networks using Contrastive Augmented Learning (2026)
  • contrastBERT: Behavioral Anomaly Detection for Malware Using Contrastive Learning (2025)
  • sysBERT: Improved Behavioral Malware Detection using BERT Trained on sys2vec Embeddings (2025)
