ASTROMER tutorials

Prepare light curves, use the pretrained weights, and classify astronomical objects.

Install ASTROMER

The original package was tested on 64-bit Python 3.8 to 3.10.

pip install ASTROMER

Colab notebooks

Run these tutorials in Google Colab.

  1. Prepare the data

    Format the available light-curve data for ASTROMER.

  2. Classify light curves from the MACHO catalog

    Use the pretrained weights with a TensorFlow model to classify light curves from the Massive Compact Halo Object survey.

  3. Classify light curves with the ALeRCE broker

    Extract ASTROMER embeddings for Zwicky Transient Facility light curves and classify them with a random forest.
